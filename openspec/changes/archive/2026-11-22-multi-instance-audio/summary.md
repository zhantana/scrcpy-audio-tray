# 实现摘要

## 交付物

| 文件 | 改动 |
|---|---|
| `scrcpy-audio-tray.ps1` | 外部实例计数 + 整路重启自愈；拆除拆进程代码 |
| `openspec/specs/phone-audio-bridge/spec.md` | 「画音必须同进程」+「抢占后整路重启」两个场景 |

## 行为

- 投屏模式恢复单进程（画面 + 声音 + `--turn-screen-off` + 鼠标侧键绑定）
- 其他投屏关闭后：约两秒检测到，整路重启一次，声音恢复，弹「声音已恢复」
- 其他投屏新开时不抢声音（后开的赢），对方退出后自动接回
- 纯音频模式行为不变

## 实测数据

设备：vivo V2546A / Android 16 / 无线 192.168.1.29

| 项目 | 结果 |
|---|---|
| 单进程投屏 8 秒音频丢样本 | 0 次 |
| 拆进程（画面 `--no-audio` + 独立音频）8 秒 | 17 次，声音碎裂 |
| 语法检查 | 通过 |

## 已知边界

- 同一台手机只有一路能出声音，属平台限制
- 声音恢复时画面闪断一两秒
- 不同手机各开一路不受影响
