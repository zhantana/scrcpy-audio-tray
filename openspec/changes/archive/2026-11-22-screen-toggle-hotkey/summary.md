# 投屏开关快捷键 — 完成总结

## 做了什么

- 新增全局快捷键，默认 F7，一键切换投屏开 / 关。开则显示主窗口，关则回纯音频、声音不断
- 复用现有 Set-Screen，不新增投屏逻辑，开关都走同一套重启流程
- 热键窗口按 WM_HOTKEY 的 wParam 分发：0x5150 暂停，0x5151 投屏
- 设置写入 settings.json 的 HotkeyScreen，支持修改 / 禁用 / 恢复默认，与 HotkeyPause 独立
- 两键相同时拒绝保存；单键注册失败只提示该键，不影响另一个
- 托盘菜单「快捷键」拆为两组；窗口菜单和快捷键说明同步显示
- 托盘已是管理员权限，游戏里按键正常送达

## 验证

- PSParser 语法检查通过
- 安装包 1.5.0 编译成功，脚本已部署到安装目录，MD5 一致
- C# 编译验证被本机安全策略拦截，未能自测；运行时行为需用户实测

## 已知限制

- 默认 F7 可能与别的软件冲突，被占用时托盘会提示换键
- 单键全局占用，按下后其他程序收不到该键
