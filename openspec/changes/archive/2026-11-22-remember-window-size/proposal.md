# 记忆横竖屏窗口尺寸

视频横竖屏切换时，同一方向的窗口尺寸每次都不一样，看起来像随机。

## 为什么（日志实测）

- 横屏分支按屏幕宽度 95% 固定算，日志里横屏一律 `2432x1159`，一致
- 竖屏分支「宽度 = 当前内容区高度 × 比例」，高度直接继承切换前的窗口高度
- 于是从横屏切回来是 1159、从初始状态切回来是 600、手动拖过是 1380——宽度跟着变

比例本身固定（0.45 / 2.2），问题是竖屏没有基准高度，拿上一状态当基准。

## 改什么

- 竖屏、横屏各记一个窗口尺寸到 `settings.json`（`SizePortrait` / `SizeLandscape`）
- 切到某方向时恢复该方向记住的尺寸；没记过才按屏幕算默认值
- 用户手动拖窗口改大小后，更新当前方向的记录
- 重启后保持

## 非目标

- 不改比例计算本身，不改音频/解锁/快捷键

## 风险

- 换分辨率或换显示器后，记住的尺寸可能不合适；可通过恢复默认或手动拖动重设
