# 变更：按连接方式组织设备（USB / Wi-Fi / 蓝牙）

## Why

现在设备列表把所有 adb 设备混在一起，用户看不出某台手机是插着线还是走的无线，也不知道菜单里的 IP 输入框属于哪种连接。同一台手机同时插线又连着 Wi-Fi 时会出现两条记录，默认还优先选了 Wi-Fi 那条——延迟和稳定性都不如 USB。

用户希望菜单里能明确看到「有线 / Wi-Fi / 蓝牙」三种连接方式。

## What Changes

- 「选择设备」菜单按连接方式分组：USB 有线、WiFi 无线、蓝牙
- 每个设备条目后面标注 `[USB]` 或 `[WiFi]`
- 默认优先 USB：同一机型同时存在两种连接时选 USB
- 插上 USB 自动切到有线，拔掉自动回落到 Wi-Fi（仅在原来走 Wi-Fi 时）
- Wi-Fi 地址持久化到 `settings.json` 的 `WifiTargets`，启动时自动重连
- 蓝牙项保留但置灰，说明 adb 不支持蓝牙，无法用于投屏和音频

## 非目标

- 不做蓝牙音频回传（Windows 当蓝牙音箱）：延迟 200ms 以上，且无法投屏
- 不改投屏、音频、解锁逻辑
- 不改 adb 本身的行为，只改设备发现与菜单组织
