# 窗口模式可切换

当前投屏只有一种显示方式：把 scrcpy 画面嵌进我们自己的窗口（带顶栏菜单）。这个嵌入实现问题多，用户想改用 scrcpy 原生窗口，也要能切回来。

## 改什么

- 新增设置 `WindowMode`：`embedded`（程序窗口，默认）或 `native`（scrcpy 原生窗口）
- 托盘菜单加「窗口模式 ▸ 程序窗口 / scrcpy 原生窗口」，勾选项，存 `settings.json`
- 切换时若正在投屏，重启一次投屏生效（画面断一两秒）
- 原生窗口模式：scrcpy 自己开窗、自己管理，不嵌入、不显示我们的主窗口

## 两种模式差异

| 功能 | 程序窗口 | scrcpy 原生窗口 |
|---|---|---|
| 菜单栏 | 有（设备/音频/视图/帮助/关于） | 无，用托盘菜单 |
| 窗口置顶 | 顶栏即时切换 | `--always-on-top`，改设置需重启投屏 |
| 息屏提示 | 窗口内覆盖层 | 贴在 scrcpy 窗口原位 |
| 全屏 | F11 我们的实现 | scrcpy 原生快捷键 |
| 横竖屏尺寸记忆 | 生效 | 不生效（scrcpy 自己管） |
| 音频/解锁/两个快捷键 | 不受影响 | 不受影响 |

## 非目标

- 不移除现有的嵌入实现，两种并存
- 不改音频、解锁、快捷键逻辑

## 风险

- 原生模式下多开投屏时窗口标题需要唯一，沿用 `--window-title` 带序列号
- 原生窗口的息屏提示仍需找到 scrcpy 窗口句柄定位
