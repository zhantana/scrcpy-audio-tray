============================================================
手机音频托盘 v2（C# / .NET 8）
============================================================

这是重构版，与 v1 并存，互不覆盖。v2 用 C# 重写，架构更清晰，
画质设置更直观。

------------------------------------------------------------
一、首次使用
------------------------------------------------------------
有线（最稳）
1. 手机「设置 → 开发者选项」打开「USB 调试」
2. 数据线插电脑，手机上点「允许 USB 调试」
3. 双击桌面「手机音频托盘 v2」启动（右下角出现图标）

无线
1. 手机打开「无线调试」，用 legacy/v1 目录里的「无线-首次配对.bat」配对过即可
2. 双击桌面图标启动

启动后自动选设备、自动开始投屏和音频转发。

------------------------------------------------------------
二、托盘菜单
------------------------------------------------------------
右键右下角图标：

  启动 / 停止投屏     开关投屏
  暂停 / 继续         暂停手机上的视频、音乐（媒体键）
  唤醒并解锁          手机锁屏时点它
  设备 >              切换设备，标注 [USB] / [WiFi]
  窗口模式 >          程序窗口 / scrcpy 原生窗口
  投屏窗口置顶        可选
  快捷键 >            修改暂停键、投屏键
  设置                画质 / 帧率 / 编码 / 缓冲
  显示 / 隐藏窗口
  重置窗口尺寸
  退出

双击托盘图标 = 启动 / 停止投屏。

------------------------------------------------------------
三、画质设置（v2 新增）
------------------------------------------------------------
视频码率    默认 16Mbps，越高越清晰，压力越大
视频编码    H.264 / H.265 / AV1
帧率上限    30 / 60 / 90（手机原生）/ 不限
分辨率      原始 / 1080p / 720p
音频缓冲    默认 40ms，越大越抗抖动

改完保存会自动重启投屏生效。

说明：帧数画质的上限由 scrcpy 和手机编码器决定，
设置只是调到适合你设备的组合。

------------------------------------------------------------
四、快捷键
------------------------------------------------------------
暂停 / 继续   默认 Ctrl+Alt+P
投屏开关      默认 F7

都是全局热键，托盘运行时随时可用。在托盘菜单里可改成任意键，
包括单键（单键会被全局占用，其他程序收不到，建议用冷门键）。
程序已提权，游戏里按也生效（启动会弹一次 UAC，点「是」）。

------------------------------------------------------------
五、已知限制
------------------------------------------------------------
* 程序窗口模式：把 scrcpy 画面嵌进我们的窗口，个别情况嵌入失败
  会自动回退到 scrcpy 原生窗口，音频不受影响
* 游戏不响应媒体暂停键（Android 侧限制），只有视频、音乐认
* 蓝牙不支持：adb 没有蓝牙通道

------------------------------------------------------------
六、卸载
------------------------------------------------------------
控制面板 → 应用 → 手机音频托盘 v2 → 卸载。
只删 v2 自己的目录，不影响 v1。
