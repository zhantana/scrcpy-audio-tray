# 本次变更差异：连接方式

## ADDED

### 场景：连接方式可见

- 设备条目后缀标注 `[USB]` / `[WiFi]`
- 判定依据序列号形态：含 `:` 或 `_adb-tls` 为 Wi-Fi，其余为 USB

### 场景：按连接方式分组

- 「选择设备」下分三组：USB 有线、WiFi 无线、蓝牙
- USB 组列出当前在线的 USB 设备，无设备时提示插线并开启 USB 调试
- WiFi 组列出已保存地址、自动发现、添加 IP、配对码配对
- 蓝牙组置灰，提示 adb 不支持蓝牙传输

### 场景：USB 优先

- 同一机型同时存在 USB 与 Wi-Fi 连接时，默认选 USB
- 用户手动选择过的设备优先于默认规则

### 场景：插拔自动切换

- 当前走 Wi-Fi 时插入同机型 USB，自动切到 USB
- 当前走 USB 时拔掉线，自动回落到在线的 Wi-Fi 设备
- 切换时通知一行，正在转发则重启转发

### 场景：Wi-Fi 地址记忆

- 连接成功的 `IP:端口` 写入 `settings.json` 的 `WifiTargets`
- 启动时依次重连，失败静默跳过
- 最多保留 8 条，重复的提到最前
