# 记忆各方向窗口尺寸 — 完成总结

## 根因（日志实测）

- 横屏按屏幕宽 95% 固定算，日志里一律 2432x1159，一致
- 竖屏「宽度 = 当前内容区高 × 比例」，高度直接继承切换前窗口高度
- 于是从横屏切回是 1159、从初始切回是 600、手动拖过是 1380，宽度跟着变，看着随机
- 比例本身固定（0.45/2.2），问题是没有基准高度

## 做了什么

- settings.json 增加 SizePortrait / SizeLandscape，读写为 [宽,高]
- Adjust-WindowToVideo 优先用记忆尺寸；没有才按屏幕默认算法算
- Start-Audio 启动开窗同样优先用记忆尺寸
- BorderlessForm 新增 ResizeEnded 事件（WM_EXITSIZEMOVE），用户拖完窗口触发，程序改尺寸不触发
- Remember-CurrentSize：按当前方向把窗口尺寸写入 settings，记日志 `size portrait=WxH`
- 托盘菜单加「重置窗口尺寸」，清空两个方向记忆
- 每次切到某方向都恢复记忆值，不再继承上一个方向的状态

## 验证

- PSParser 语法检查通过

## 已知限制

- 换分辨率或显示器后记忆尺寸可能不合适，用「重置窗口尺寸」重设
