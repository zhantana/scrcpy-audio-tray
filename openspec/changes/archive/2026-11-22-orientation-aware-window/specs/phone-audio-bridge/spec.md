## ADDED Requirements

### Requirement: 窗口跟随手机方向

系统 SHALL 检测手机横竖屏方向，并让投屏窗口比例跟随，保证画面完整显示不被裁切。

#### Scenario: 竖屏投屏

- **GIVEN** 手机竖屏，视频为 1440x3168
- **WHEN** 开始投屏
- **THEN** 窗口为窄高比例（宽÷高≈0.45）
- **AND** 画面完整铺满内容区

#### Scenario: 转到横屏

- **GIVEN** 正在竖屏投屏
- **WHEN** 手机转到横屏（mRotation 为 90 或 270）
- **THEN** 检测到方向变化
- **AND** 窗口改为宽扁比例（宽÷高≈2.2）
- **AND** 画面完整显示，两侧不再被裁掉
- **AND** 音频与解锁不受影响

#### Scenario: 转回竖屏

- **GIVEN** 正在横屏投屏
- **WHEN** 手机转回竖屏（mRotation 为 0 或 180）
- **THEN** 窗口恢复窄高比例

#### Scenario: 方向未知

- **GIVEN** adb 读不到方向信息
- **WHEN** 轮询执行
- **THEN** 不改变窗口，维持现状
- **AND** 不弹错误提示

#### Scenario: 横屏超出屏幕

- **GIVEN** 横屏按比例算出的窗口高度超过屏幕工作区
- **WHEN** 调整窗口
- **THEN** 高度按工作区封顶，宽度按比例回算
- **AND** 窗口始终不超出屏幕
