# 实现摘要

## 交付物

| 文件 | 作用 | 状态 |
|---|---|---|
| `启动-手机音频托盘.vbs` | 日常入口，静默拉起托盘 | 可用 |
| `scrcpy-audio-tray.ps1` | 托盘主程序 | 语法与逻辑已验证，UI 待用户实测 |
| `无线音频-游戏模式.bat` | 纯音频无线转发 | 实测通过 |
| `无线-首次配对.bat` | 首次配对 | 实测通过 |
| `手机声音到电脑-低延迟游戏模式.bat` | 有线纯音频 | 可用 |
| `手机投屏带声音.bat` | 有线投屏+声音 | 可用 |

## 实测数据

- 设备：vivo V2546A / Android 16
- 无线延迟：60–100ms（`raw` + 40ms 缓冲）
- 有线延迟：40–60ms
- 转发 4 秒限时运行无报错

## 过程中修掉的 bug

1. `.bat` UTF-8 编码导致长中文行截断 → 改 GBK
2. scrcpy 改写控制台代码页 → 结尾 `chcp 936` 复原
3. `for /d` 多级通配符失效 → 逐层遍历
4. `title` 中 `->` 被当成重定向符 → 转义
5. 同一设备两条 adb 记录 → 按 model 去重 + `-s` 指定
6. mDNS 正则写成 `.tcp` 而非 `_tcp`，去重长期未生效 → 已修正

## 遗留

- 托盘 UI 未经真实点击验证（沙箱禁止脚本拉起 PowerShell）。异常会写 `tray-error.log`。
- 两台真机同时在线的场景未实测。
- 无线调试关闭后，部分 ROM 会清除配对关系，需重新配对。
