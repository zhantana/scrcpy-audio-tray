# 完成情况

## 改了什么

菜单「选择设备」重排为三组：

- **USB 有线**：列出在线 USB 设备，没有时提示插线并开 USB 调试
- **WiFi 无线**：在线无线设备、已保存地址（点一下重连）、自动发现并连接、添加 IP、配对码配对
- **蓝牙（不可用）**：置灰，悬停提示 adb 不支持蓝牙

每个设备条目带 `[USB]` / `[WiFi]` 后缀。判断只看序列号形态：含 `:` 或 `_adb-tls` 是无线，其余是有线。

## 行为变化

| 场景 | 旧 | 新 |
|---|---|---|
| 默认选哪台 | 优先 IP 形式（无线） | 优先 USB |
| 插上数据线 | 不反应 | 5 秒内切到有线，重启转发并通知 |
| 拔掉数据线 | 设备直接消失 | 自动回落到在线的无线连接 |
| 无线地址 | 记在 wifi_target.txt，仅一条 | 记在 `settings.json` 的 `WifiTargets`，最多 8 条 |
| 用户手动选的设备 | 无记忆 | 不被自动切换抢走（当次运行内） |

节流：形态检测每 5 秒一次，两次自动切换至少间隔 5 秒，只认机型（`model`）相同的设备，避免误切到另一台手机。

## 遗留

- 蓝牙确定不做。adb 只有 USB / TCP 两种 transport，scrcpy 无法走蓝牙
- 自动切换会重启转发，画面会闪断 1~2 秒，与多实例抢音频时的处理一致
